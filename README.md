# Sales Manager — Fundamentos de Java ☕

Este é um projeto simples, desenvolvido durante meus estudos de Java, com o objetivo de colocar em prática os conceitos fundamentais da linguagem.

O projeto simula um pequeno sistema de controle de vendas, permitindo registrar vendas, consultar o total vendido, calcular comissões e verificar o atingimento de metas.

## Funcionalidades

- Registrar vendas
- Consultar o total vendido
- Calcular comissão de 5% sobre as vendas
- Verificar se a meta de R$ 10.000 foi atingida
- Navegar por um menu interativo no console

## Conceitos praticados

Durante o desenvolvimento deste projeto, pratiquei:

- Variáveis e tipos de dados
- Entrada de dados com `Scanner`
- Estruturas condicionais (`if/else`)
- Estrutura de decisão (`switch/case`)
- Laços de repetição (`while`)
- Criação e utilização de métodos
- Parâmetros e retorno de valores (`double` e `boolean`)

## Tecnologias utilizadas

- Java
- IntelliJ IDEA

## Sobre o projeto

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento Java.

A ideia foi aplicar os conhecimentos adquiridos durante os estudos em um exercício prático, trabalhando principalmente a lógica de programação e a organização do código.

O sistema ainda é simples e funciona pelo terminal, mas pretendo evoluí-lo conforme avanço nos estudos de orientação a objetos e outros conceitos da linguagem.
